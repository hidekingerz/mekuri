# mekuri - 要件定義書

## 概要

**mekuri** は、圧縮ファイル（ZIP/RAR等）内の画像および PDF ファイルを見開き表示で閲覧するためのデスクトップアプリケーションである。Tauri v2（Rust + React）で構成される。

## 用語定義

| 用語 | 説明 |
|------|------|
| アーカイブ | ZIP, RAR 等の圧縮ファイル |
| PDF | PDF 形式のファイル（pdfjs-dist でレンダリング） |
| 見開き表示 | 2ページを左右に並べて表示するモード |
| 単ページ表示 | 1ページずつ表示するモード |
| 読み方向 | ページの進行方向。RTL（右→左、漫画等）と LTR（左→右、PDF等）がある |
| フォルダツリー | ディレクトリ階層をツリー形式で表示するUI |
| お気に入り | ユーザーが登録したルートフォルダの一覧 |
| ネストアーカイブ | アーカイブ内に含まれるアーカイブファイル |
| 兄弟アーカイブ | 同一フォルダ内の他のアーカイブファイル |

## ウィンドウ構成

アプリケーションは2つのウィンドウで構成される。

### 1. メインウィンドウ

お気に入りフォルダの管理、フォルダツリーによるファイルブラウジング、アーカイブファイルの一覧表示を担当する。3カラムレイアウトで構成される。

**機能要件:**

- FR-M1: お気に入りフォルダを登録・削除できる（フォルダ選択ダイアログまたはコンテキストメニュー）
- FR-M2: お気に入りフォルダ配下をフォルダツリーとして表示する
- FR-M3: フォルダの展開・折りたたみができる
- FR-M4: サブフォルダを持たないフォルダはシェブロン（展開アイコン）を非表示にする
- FR-M5: 選択中のフォルダ内のアーカイブファイルおよび PDF ファイルをファイルリストとして一覧表示する
- FR-M6: アーカイブファイル（ZIP/RAR）および PDF をアイコンで識別表示する
- FR-M7: アーカイブファイルまたは PDF をダブルクリックするとビューワーウィンドウを開く（シングルクリックは選択）
- FR-M8: 同じアーカイブが既に開かれている場合は、そのウィンドウにフォーカスする
- FR-M9: フォルダツリーのコンテキストメニューからフォルダをお気に入りに追加できる
- FR-M10: フォルダツリーとファイルリストの境界をドラッグしてカラム幅を変更できる
- FR-M11: 隠しファイル（`.` で始まるファイル・フォルダ）は表示しない
- FR-M12: ディレクトリ・アーカイブの表示順は自然順ソート（FR-V1 と同じ並べ方）とし、ディレクトリを先に表示する
- FR-M13: ファイルリストはクリックまたは ↑↓ キーで選択（範囲選択の起点）、Enter で選択中のファイルをすべて開くことができ（選択していないファイルは開かない。2 件以上のときは、ビューワーウィンドウを少しずつ右下へずらして並べる）、Cmd+クリック（macOS 以外は Ctrl+クリック）でトグル、Shift+クリックで起点からその項目までの範囲に選択を置き換えることができ、コンテキストメニューまたは Delete キー（fn+Delete）/ Cmd+Backspace で選択したファイルをまとめてゴミ箱へ移動できる（確認ダイアログは 1 回）。Esc で選択解除。一覧から消えたファイル（移動した・別のウィンドウで消した）は選択から外す。ゴミ箱へ移せなかったときはエラーを表示する
- FR-M14: ファイルリストのヘッダーに件数を表示し、名前 / 更新日時 / サイズで昇順・降順に並べ替えられる
- FR-M15: フォルダツリーのコンテキストメニューから、フォルダを中身ごとゴミ箱へ移動できる。確認ダイアログに、中にあるファイルリストに出るファイル（アーカイブと PDF。サブフォルダを含み、隠しファイルは除く）の数を表示し、初期フォーカスはキャンセルに置く。キーボードショートカットは設けない。お気に入りのフォルダ自体は、お気に入りの一覧からはゴミ箱へ移せない。別のお気に入りのツリーに出ているお気に入り（とそれを中に含むフォルダ）は移すことができ、そのときはお気に入りの登録も外し、外す件数を確認ダイアログに表示する。消したフォルダかその中を選んでいた場合は親フォルダを選んだ状態にする
- FR-M16: Finder からドラッグしたファイルを、フォルダツリー・お気に入りのフォルダ・ファイルリスト（表示中のフォルダ）に落とすと、そのフォルダへ移動する。検索中は、一致したフォルダの行（フォルダの一覧と検索結果のどちらも）に落とすとそのフォルダへ移動し、検索結果の余白では受け付けない。アプリ内のドラッグも同じ行へ落とせる。同名ファイルがある場合やフォルダを落とした場合は移動せずエラーを表示する
- FR-M17: ビューワでファイルを開くと、そのファイルがあるフォルダを「最近開いたフォルダ」に記録する（新しい順に最大 10 件、1 フォルダ 1 件、アプリ終了後も保持）。フォルダを選んだだけでは記録しない。何も選んでいないときはファイルリストの位置に一覧を表示し、フォルダ表示中はファイルリストの見出しの「最近」ボタンから開く。各項目はフォルダ名・最後に開いたファイル・お気に入りからの場所・開いた日を示し、選ぶとそのお気に入りとフォルダを選んでツリーを展開する。存在しないフォルダ、どのお気に入りにも含まれないフォルダ、表示中のフォルダは出さない

### 2. ビューワーウィンドウ

アーカイブ内の画像を見開き表示する。

**機能要件:**

- FR-V1: アーカイブ内の画像ファイルを自然順（natural sort）でソートして表示する。数字は数値の小さい順に並べ（`1, 02, 03, 10`、`p8, p9, p010`。ゼロ埋めの有無は問わない）、大文字と小文字は区別しない（`a1, A2, a10`）
- FR-V2: 見開き表示（2ページ並列）をデフォルトとする
- FR-V3: ページ送り（次へ/前へ）ができる（キーボード・クリック・マウスホイール）。修飾キー（Shift・Alt・Ctrl・Cmd）を押しながらのキーとホイールでは送らない。確認ダイアログが開いているあいだは、キーとホイールで後ろのページを送らない
- FR-V4: 読み方向を RTL（右→左）と LTR（左→右）で切り替えられる
  - アーカイブはデフォルト RTL、PDF はデフォルト LTR
  - 読み方向に応じてページ配置・クリック領域・キーボード操作・プログレスバーの進行方向が反転する
- FR-V5: 画像をウィンドウサイズに合わせてフィットさせる
- FR-V6: 先頭ページ（表紙）は単ページ表示とする
- FR-V7: アーカイブ内にネストされたアーカイブがある場合、選択UIを表示する
- FR-V8: ネストアーカイブを一時ファイルとして展開し、閲覧できる
- FR-V9: プログレスバーを表示し、クリックで任意のページにジャンプできる
- FR-V10: Alt+上下矢印キー、マウスの戻る・進むボタン、フッターのボタン、コンテキストメニューから同一フォルダ内の兄弟アーカイブに移動できる（先頭・末尾では該当操作を無効化する）。確認ダイアログが開いているあいだは移動しない。開いているファイルが一覧に無いとき（別のウィンドウで消された・動かされた、開く前から無かった）は、名前の並び順で入るはずの位置の前後へ移る
- FR-V11: ウィンドウタイトルにファイル名と現在位置を表示する（例: `file.zip [3/10] - mekuri`）
- FR-V12: 見開き表示と単ページ表示を切り替えられる。3 ページ表示と、ウィンドウの幅に入る枚数を並べるウィンドウ追従表示にも切り替えられる。切り替えても読んでいた位置を保つ
- FR-V13: PDF ファイルをページ画像としてレンダリングして表示する（pdfjs-dist 使用、CJK フォント対応）
- FR-V14: 右クリックのコンテキストメニューから表示モード切替・前後ファイル移動・読み方向切替・ゴミ箱移動・ウィンドウクローズができる。ゴミ箱への移動は確認のあとにだけ実行し、移したあとは次のファイル（無ければ前のファイル）を開く。ほかにファイルが無ければウィンドウを閉じる。ページを表示していない画面（開けない・空・ネストの選択）では、表示モードと読み方向の項目は選べない。確認ダイアログが開いているあいだはメニューを出さない
- FR-V15: 幅が高さより大きいページ（1 枚に見開きが入ったスキャン）は、見開き・3 ページ・ウィンドウ追従の各モードで常に単独表示する。横長かどうかは画像を読み込んで初めて分かるので、分かった時点で組み直す。前へ戻るとき・最後へ飛ぶときも、横長のページを飛ばさない
- FR-V16: ファイルを開けないときや中身が空のときも、画面上から前後のファイルへの移動とウィンドウを閉じる操作ができ、ゴミ箱への移動（Delete、Cmd+Backspace、メニュー）もできる。エラーは人向けの一次文で示し、生のメッセージは詳細として折りたたむ。ネストしたアーカイブの展開に失敗したときは、画面から選択の一覧へ戻れる

### キーボード操作

キーボード操作は読み方向に応じて動作が変わる。ページ送りのキー（Space・←・→・Home・End）は、修飾キーを押しているあいだは働かない。フッターのボタンにフォーカスがあっても、Space はページ送りになる。

| キー | RTL（右→左） | LTR（左→右） | コンテキスト |
|------|-------------|-------------|------------|
| Space | 次の見開きへ | 次の見開きへ | ビューワー |
| ← | 次の見開きへ | 前の見開きへ | ビューワー |
| → | 前の見開きへ | 次の見開きへ | ビューワー |
| Home | 最初の見開きへ | 最初の見開きへ | ビューワー |
| End | 最後の見開きへ | 最後の見開きへ | ビューワー |
| マウスホイール | ページ送り（200ms のあいだは 1 回だけ送る） | 同左 | ビューワー |
| Alt+↓ | 次の兄弟ファイルへ（ファイル一覧で下の項目） | 同左 | ビューワー |
| Alt+↑ | 前の兄弟ファイルへ（ファイル一覧で上の項目） | 同左 | ビューワー |
| マウス戻るボタン (button 3) | 前の兄弟ファイルへ | 同左 | ビューワー |
| マウス進むボタン (button 4) | 次の兄弟ファイルへ | 同左 | ビューワー |

### コンテキストメニュー（ビューワー）

| メニュー項目 | 動作 |
|-------------|------|
| 単ページ表示 / 見開き表示 / 3ページ表示 / ウィンドウ追従表示 | 表示モードを切り替える（いまのモードにチェックが付く） |
| 次のファイル / 前のファイル | 同一フォルダ内の兄弟ファイルへ移動する（端では無効） |
| 左→右 (LTR) に切替 / 右→左 (RTL) に切替 | 読み方向を切り替える（いまと逆の向きが項目名になる） |
| ゴミ箱に移動 | 確認のあと、ファイルをゴミ箱に移動する |
| ウィンドウを閉じる | ビューワーウィンドウを閉じる |

### 設定の永続化

以下の設定は `tauri-plugin-store` により自動保存・復元される。

| 設定項目 | デフォルト値 |
|----------|------------|
| メインウィンドウサイズ | 1000 x 700 |
| ツリーカラム幅 | 300px |
| ビューワーウィンドウサイズ | 1200 x 900 |
| 表示モード | 見開き表示 |
| 読み方向 | ファイル種別による（アーカイブ: RTL、PDF: LTR） |
| お気に入りフォルダ一覧 | 空 |

## 対応フォーマット

### アーカイブ形式

| 形式 | 拡張子 |
|------|--------|
| ZIP | .zip, .cbz |
| RAR | .rar, .cbr |

注: `.7z` はフォルダツリー上でアーカイブとして認識されるが、画像抽出処理は未実装。

### PDF

| 形式 | 拡張子 |
|------|--------|
| PDF | .pdf |

PDF はフロントエンドで `pdfjs-dist` を使ってページ画像にレンダリングする。CJK フォント（日本語・中国語・韓国語）にも対応する。

### 画像形式（アーカイブ内）

| 形式 | 拡張子 |
|------|--------|
| JPEG | .jpg, .jpeg |
| PNG | .png |
| WebP | .webp |
| GIF | .gif（静止画として） |

## 非機能要件

- NFR-1: ページ送り操作はストレスなく行える応答速度とする
- NFR-2: Windows / macOS / Linux で動作する（Tauri対応プラットフォーム）
- NFR-3: 大量の画像を含むアーカイブ（1000枚以上）でもメモリを圧迫しない
