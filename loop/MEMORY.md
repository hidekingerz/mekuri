- 作業ディレクトリ（cwd）はリポジトリルート。ループ用ドキュメントは `loop/` 配下。VERIFY は `cd deno-app && deno task verify`。

- 正解は元の Tauri 実装（`src-tauri/`）と React フロント（`src/`）の挙動。移植時は対応する Rust ファイルを読んで仕様を合わせる。
